# freeeファイルボックスのインボイス情報コピー

freee MCPを使い、ファイルボックスの過去ファイルを基準に、直近登録ファイルのインボイス情報を更新する。ブラウザ操作やfreee APIへの直接HTTP通信は使わない。

## 実行手順

1. `freee_auth_status` で認証状態を確認する。未認証なら認証を開始し、認証完了後に続行する。
2. `freee_get_current_company` で事業所IDと事業所名を確認する。会社を推測してはいけない。
3. `freee_api_get` で会計サービスの `/api/1/receipts` を取得する。`company_id`、対象期間、`category=all`、必要な `limit` を指定し、`created_at` の新しい順に並べる。
4. 直近登録ファイルを、削除済み・無視済みを除いて特定する。ユーザーが対象IDや期間を指定した場合はそれを優先する。
5. ユーザーが指定した「前の」「基準」ファイルを同じ一覧または詳細取得で特定し、`freee_api_get` の `/api/1/receipts/{id}` で次の値を確認する。
   - `qualified_invoice`
   - `invoice_registration_number`
   - 必要に応じて `document_type`
6. 基準ファイルが特定できない、候補が複数ある、またはインボイス登録番号が不正な場合は更新せず、候補と不足情報を示す。
7. ユーザーが更新を依頼している場合だけ、直近ファイルに対して `freee_api_put` の `/api/1/receipts/{target_id}` を実行する。`company_id` と、依頼されたインボイス項目だけを送信し、無関係なメモ・日付・金額・発行元は変更しない。
8. 更新後、同じ対象を `freee_api_get` で再取得し、指定した値が一致することを確認する。

## インボイス情報の扱い

- `qualified_invoice` は `qualified`、`not_qualified`、`unselected` のいずれかを使う。
- `invoice_registration_number` は `T` + 13桁の登録番号だけを設定する。
- ユーザーが「インボイス情報」とだけ指定した場合は、原則として上記2項目だけをコピーする。`document_type` は証憑の種類まで揃える明示的な依頼がある場合だけ更新する。
- 基準ファイルのfreee上の値が未設定なら、PDFやメール本文から補完してよいかを確認する。確認なしに別ソースの値を基準値として書き込まない。
- 更新対象は直近ファイル1件に限定する。複数ファイルの一括更新は、ユーザーが明示した場合だけ行う。

## 報告

完了時は、事業所名、基準ファイルID、更新対象ファイルID、変更した項目、更新後の確認結果を簡潔に報告する。認証情報やメール本文などの不要な個人情報は出力しない。
